# 操作指引（新手一步一步版）

> 这篇文档假设你**没有用过命令行**，只会双击文件。
> 每个步骤都写了「你会看到什么」和「你要做什么」，照着做即可。
> 程序界面文字可能随版本略有调整，以你屏幕上显示的为准。
> 出错时不用慌，先看最后一节「四、出错怎么办」。

---

## 一、首次使用：从安装到提交第一篇（10 步）

### 步骤 1：下载并解压

**你会看到**：一个压缩包（通常是 `xyb-journal-main.zip` 这类名字）。

**你要做**：
1. 把压缩包解压到一个你找得到的位置，例如 `D:\xyb-journal`。
2. 解压后打开文件夹，应该能看到 `install.bat`、`start.bat`、`docs`、`xyb` 等文件和文件夹。
3. **不要**在压缩包预览窗口里直接双击，一定要先解压。

> 路径里带中文一般也能用；如果后面遇到奇怪的启动问题，优先换到纯英文路径再试。

### 步骤 2：双击 `install.bat`

**你会看到**：一个黑色窗口，标题是 `xyb-weekly-journal - Installer`，然后依次显示：

```text
[1/4] 检查 Python 版本：3.x.x
  [OK] 版本满足要求（需 3.10+）
[2/4] 安装 Python 依赖（首次约 1-3 分钟，需要联网）
[3/4] 检查 Google Chrome
[4/4] 准备配置文件
```

最后显示：

```text
安装完成！

下一步：双击 start.bat 启动
首次启动会自动引导你：
  ① 填写 DeepSeek API Key（用于生成周志正文）
  ② 扫码登录校友邦（只需一次）
登录完成后，在菜单里选 [2] 就能写第一篇周志。
```

并提示按任意键。

**你要做**：
1. 双击 `install.bat`。
2. 等它跑完。第一次安装要联网下载依赖，**1～3 分钟**算正常，不要中途关窗口。
3. 看到「安装完成」后按任意键关闭窗口。

**可能遇到**：
- 提示 `Python not found on this computer`（未检测到 Python）：安装脚本会尝试用 winget 自动装 Python。
  如果自动安装成功，按提示**关闭窗口，重新双击一次 `install.bat`**。
  如果不能自动安装，按窗口里的网址手动下载 Python（安装时务必勾选 **Add python.exe to PATH**）。
- 提示依赖安装失败：先检查网络，重新双击 `install.bat` 再试一次。
- 提示未检测到 Chrome（`[X] 未检测到 Google Chrome`）：到 <https://www.google.com/chrome/> 安装 Chrome，
  然后重新双击 `install.bat` 检查一遍。安装脚本不强制阻止后续步骤，但没有 Chrome 无法登录。

> 安装的 Python 依赖只有 4 个（requests、playwright、qrcode、pillow），
> **不需要**额外执行 `playwright install` 下载浏览器，程序直接使用你本机的 Chrome。

### 步骤 3：申请 DeepSeek API Key

**你会看到**：浏览器里的 DeepSeek 开放平台页面。

**你要做**：按 [AI接口接入.md](AI接口接入.md) 第 1 节操作：

1. 打开 <https://platform.deepseek.com/>，注册/登录。
2. 左侧「API keys」→「创建 API key」。
3. 复制 `sk-` 开头的字符串（只显示一次），临时存到记事本。
4. 到「充值」页面充值。

> 这一步不用所有细节都记住，跟着链接里的编号做就行。

### 步骤 4：第一次双击 `start.bat`

**你会看到**：黑色窗口，先是欢迎语：

```text
欢迎使用 校友邦周志助手 v1.0.0
首次使用需要完成 3 件事：
  ① 填写 DeepSeek API Key（用于生成周志正文，申请方法见 docs/AI接口接入.md）
  ② 扫码登录校友邦（只需一次）
  ③ 生成并提交你的第一篇周志（登录后在菜单选 [2]）
按回车键开始配置…
```

**你要做**：按一下回车。

> 欢迎语里的第 ③ 项只是告诉你接下来的步骤，程序**不会自动写第一篇**；
> 配置和登录完成后，需要你自己选菜单 `2` 开始写。
> 以后再次打开程序时不会再出现这段欢迎语，而是直接进入主菜单，这是正常的。

### 步骤 5：填 API Key 和基本信息

**你会看到**：连续的提问，一共 9 项：

```text
1) DeepSeek API Key（sk- 开头的字符串，输入时不显示）
2) 模型名称（当前：deepseek-chat）
3) 实习单位名称（留空=自动从校友邦读取）
4) 实习岗位（留空=自动读取）
5) 主要工作内容（一句话，例如：参与后端接口开发与维护）
6) 常见日常任务（用逗号分隔，可留空）
7) 用到的技术/工具（用逗号分隔，可留空）
8) 每篇最少字数（学校要求，留空保持） （当前：320）
9) 每篇最多字数（留空保持） （当前：620）
```

**你要做**：
1. 第 1 项：粘贴你的 Key，回车。**输入时屏幕上不会显示内容，这是正常的**。
   （还没申请到 Key 的话，先看步骤 3；暂时也可以按回车跳过，但生成周志前必须配好。
   如果一直跳过不填，下次启动还会再次出现欢迎语和配置向导，填好 Key 后就不会了。）
2. 第 2 项：直接回车保持默认（默认 `deepseek-chat`）。
3. 第 3～5 项：可以留空直接回车。程序运行时会自动从校友邦读取单位、岗位；
   如果你知道系统里读不到，可以手动填一句。
4. 第 6～7 项：填不填都行，填了写出来更具体（例如：接口开发, 写测试；Java, MySQL）。
5. 第 8～9 项：不知道就回车保持默认。学校要求更高时，程序会按系统里的要求自动抬高下限。
6. 最后会问「要现在测试一下 Key 能不能用吗？」，输入 `y` 回车。
   - 显示「连通正常」：Key 配置成功。
   - 显示失败：按提示看 [AI接口接入.md](AI接口接入.md) 第 4 节报错对照表。

保存成功的提示类似：

```text
已保存：...\xyb\config.json
```

### 步骤 6：扫码登录

**你会看到**：填完配置后，程序自动进入登录检查，终端显示：

```text
正在启动浏览器检查登录状态…
如果弹出提示要求登录：请用「校友邦学生版小程序」扫一扫（不是微信扫一扫）
```

> 这时不一定弹出 Chrome 窗口：程序在后台运行 Chrome，重点看终端打印的地址和二维码页面。
> 以后登录失效需要重新扫码时，选菜单 `1` 也会回到这个扫码流程。

如果之前没登录过，终端会接着打印一个本地网页地址：

```text
需要登录。请用浏览器打开下面地址，并用「校友邦学生版小程序」扫码：
     http://127.0.0.1:8765/
二维码图片也已保存： ...\xyb\qr.png
```

**你要做**：
1. 打开电脑上的浏览器，在地址栏输入 **`http://127.0.0.1:8765/`** 并回车。
   - 如果这个页面没有自动出现，就手动输入地址；也可以直接双击打开 `xyb\qr.png` 看二维码图片。
2. 打开手机微信，搜索并进入 **「校友邦学生版」小程序**。
3. 在小程序里找到 **扫一扫**，扫电脑屏幕上的二维码，手机上按提示确认登录。
4. 看电脑页面上的状态变化：

```text
等待扫码 → 已扫描，等待手机确认 → 登录成功
```

**最常见的坑**：必须用**「校友邦学生版小程序」里的扫一扫**，
**不能用微信首页右上角的「+」→ 扫一扫**。用微信扫会没反应，或者扫出来是一串英文和符号（JSON）。

登录成功后，终端会显示类似：

```text
登录成功：（你的昵称） | （你的学校）
登录态已保存在本机，之后可直接使用其它功能。
```

> 登录态只保存在本机的 `chrome-profile` 目录，程序**不保存**你的校友邦账号密码。
> 登录一次通常可以复用很多天，失效了再扫一次即可（用菜单 1）。

（此处可自行截图：本地二维码页面）

### 步骤 7：生成本周周志

**你会看到**：登录完成后回到主菜单：

```text
==============================================================
  校友邦周志助手  v1.0.0
  自动生成实习周志 → 预览确认 → 提交校友邦
==============================================================
  AI Key：已配置（sk-abc…1234）
  配置文件：...\xyb\config.json
--------------------------------------------------------------
  [1] 登录 / 检查登录状态
  [2] 写本周周志（生成 → 预览 → 确认 → 提交）
  [3] 批量补交历史周（先生成预览，确认后再提交）
  [4] 质检已生成的内容
  [5] 刷新本地归档（从校友邦回读）
  [6] 修改配置（AI Key / 实习信息 / 字数）
  [7] 查看使用说明
  [0] 退出
--------------------------------------------------------------
请输入编号后按回车：
```

**你要做**：
1. 输入 `2`，回车。
2. 程序会先问一句：

   ```text
   本周有什么真实素材？（例如：主要在做排序算法优化，可留空）
   ```

   如果你这周确实做了点事，用一句话写下来（例如「这周在调接口联调，帮同事改了几个测试用例」），
   写出来生成的正文会更像你本人写的。没有就**直接回车**。
3. 接下来程序会自动连接校友邦，显示读取到的信息：

   ```text
   登录身份：... | ... | 学号ID ...
   实习计划：... | 项目：...
   实习时间：2026.10.19 ~ 2026.10.23 | 状态：...
   周志要求：至少 350 字 | 周期 1 周 | 标题要求：...
   实习单位：... | 岗位：...
   周次共 16 周，未提交 5 周
   ```

4. 然后显示「生成正文中（调用 DeepSeek）…」，等十几秒到一分钟。

### 步骤 8：逐字核对（最重要的一步）

**你会看到**：标题、字数、分隔线、正文内容，最后是确认提示：

```text
标题：后端开发实习生实习周志（第 6 周）
字数：约 420 字（要求 ≥ 350）
------------------------------------------------------------------
（正文，通常分 3～4 段）
------------------------------------------------------------------
确认提交这一篇到校友邦？ [y/N]
```

**你要做**：认真读一遍，重点检查：

- 单位、岗位、周次对不对；
- 写的事情是不是你这周**真的做过**，能不能向老师解释清楚；
- 有没有出现编造的数字、项目名、客户名、同事姓名（AI 偶尔会自作主张）；
- 字数是否达到学校要求；
- 有没有大段空话、明显的英文单词或不自然的地方。

**不满意怎么办**：输入 `n` 回车，这次就不提交（不会产生提交记录）。
然后重新选菜单 2 生成一次；或者到菜单 6 调整「主要工作内容 / 任务 / 字数」后再试。
如果总是不满意，与其反复生成，不如自己按实际经历到校友邦网页端手动修改提交。

**可以接受**：输入 `y` 回车。

（此处可自行截图：预览正文和确认提示）

### 步骤 9：确认提交结果

**你会看到**：

```text
提交返回：code=200 msg=...
已在校友邦列表中确认：后端开发实习生实习周志（第 6 周） | 状态：已提交
已归档到：...\周志记录\周志记录.md
```

**你要做**：
1. 打开校友邦（网页或小程序），刷新周志列表，确认这一周已经出现。
   - 如果列表暂时没出现，等 1～3 分钟再刷新，可能是页面缓存。
2. 打开 `周志记录\周志记录.md`，确认新增了这周的内容。

### 步骤 10：退出

**你会看到**：提交后按回车回到主菜单。

**你要做**：
1. 输入 `0`，回车，看到「再见。」后关闭窗口。
2. 如果浏览器里还开着 `http://127.0.0.1:8765/` 的二维码页面，可以一并关掉。

## 二、日常每周怎么用（3 步）

1. **双击 `start.bat`**，输入 `1`，回车。
   - 程序会检查登录状态；没失效就直接通过，不用再扫码。
   - 如果提示要登录，按第一次的扫码方法重新扫一次。
2. **输入 `2`**，回车，等它生成本周周志。
   - 如果本周在系统里已经提交过，程序会提示「这篇已提交过，跳过」，不会重复提交。
3. **核对正文，输入 `y` 提交**；提交后到校友邦刷新列表确认，再去 `周志记录\周志记录.md` 看一眼归档。

> 每周建议固定时间做，例如周五下午或周日晚。拖延到期末再补，容易遇到截止时间或补交限制。

## 三、批量补交历史周（一定先看预览再提交）

适合：前面几周忘了写，校友邦里还显示「未提交」。

**你会看到 & 你要做**：

1. 双击 `start.bat`，输入 `3`，回车。

2. 程序问：

   ```text
   要补哪些周？（例如 1-9；直接回车=全部未提交的周）
   ```

   - 先期建议填一个小范围，例如 `1-3`，试一下效果。
   - 直接回车 = 所有未提交的周（可能很多，第一次不建议）。

3. 程序进入「第 1 步：生成正文」，逐周显示标题和字数：

   ```text
   —— 生成第 1 周 ——
     标题：... | 字数：约 400
     首句：...
   ```

   全部生成完后，会打印预览文件路径，类似：

   ```text
   已生成 3 篇，预览文件：...\周志记录\待提交预览_第1-3周.md
   ```

4. 程序问「要现在打开预览文件逐篇看吗？(y/n)」，输入 `y` 回车。
   - 会用你电脑的默认程序打开这个 `.md` 文件。
   - 如果打开后是浏览器或空白，右键文件 →「打开方式」→「记事本」也能看。
   - **这一步只是生成，还没有提交，不用紧张。**

5. 在预览文件里逐篇核对：单位、周次、标题、字数、内容是否真实。
   发现问题就记住是哪一周。

6. 程序接着进入「第 2 步：质检」，检查字数、英文残留、周与周之间是否太像。
   看到 `[问题]` 开头的行，就是需要处理的周。全部通过会显示「全部通过」。

7. 程序最后问：

   ```text
   确认以上内容没问题、现在全部提交到校友邦吗？(yes/n)
   ```

   - 确认无误：输入 `yes` 回车（默认是 `n`，直接回车等于取消）。
   - 有问题：直接回车取消。**取消不会提交任何内容**，本次生成的内容仍保存在本机；
     下次重新选菜单 3 走一遍即可（最稳的做法），所以请在这一次看仔细。

8. 提交完成后，程序会自动刷新本地归档（菜单 5 的那套动作）。到校友邦列表逐周确认，
   再打开 `周志记录\周志记录.md` 核对篇数。

**安全习惯**：
- 一次不要补太多，先 2～3 周试水。
- 预览没看完，绝不输入 `yes`。
- 能补交不代表学校允许补交，先确认学校规定（见 `README.md` 的 FAQ）。

（此处可自行截图：批量补交的预览文件）

## 四、出错怎么办

先记住一句话：**别急着重复提交，先把错误信息留下来。**

1. **不要马上关窗口**：把最后几行错误文字复制下来，或拍张照片。
2. 按关键词查 `README.md` 的「常见问题 FAQ」，里面按「症状 → 原因 → 解决」整理。
3. 常见情况的快速判断：

| 你遇到的 | 先做什么 |
| --- | --- |
| 二维码扫了没反应 / 扫出来是一串文字 | 换成「校友邦学生版小程序」里的扫一扫，不是微信扫一扫。 |
| 提示「701 安全校验已升级」 | 程序一般会自动刷新重试；连续失败就关掉重开，稍后再试。 |
| DeepSeek 报 401 / 402 / 429 / 超时 | 看 [AI接口接入.md](AI接口接入.md) 第 4 节报错对照表。 |
| 提示未检测到 Python / 缺依赖 / 环境检查未通过 | 重新双击 `install.bat`；仍不行看 README FAQ。 |
| 提示找不到 Chrome | 安装 Google Chrome 后重试。 |
| 双击 `start.bat` 窗口一闪而过 | 通常是环境没装好，看 README FAQ 的对应条目。 |
| 提交后列表没出现 | 等 1～3 分钟刷新；不要反复提交，先确认登录的是不是同一个账号。 |

4. 确认是程序本身的问题、需要反馈时：
   - 到 GitHub 仓库提 Issue；
   - 附上报错文字和复现步骤；
   - **发之前删掉** API Key、姓名、学号、学校、单位等个人信息，截图里也要打码。

## 五、几个名词小抄

| 名词 | 在这里指什么 |
| --- | --- |
| **菜单** | 双击 `start.bat` 后出现的黑底白字列表，输入数字选择功能。 |
| **登录态** | 你扫码登录一次后保存在本机 `chrome-profile` 里的登录凭证，不用每次扫码。 |
| **API Key** | 调用 DeepSeek 的钥匙，存在 `xyb/config.json`，不要外发。 |
| **预览** | 提交前给你看的正文，看到确认提示时输入 `y` 才会真正提交。 |
| **归档** | 本地的 `周志记录\周志记录.md`，记录已提交的周志内容。 |
| **批次** | 菜单 3 一次生成的多篇待提交周志，先质检再一起提交。 |
