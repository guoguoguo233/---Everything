# AI 接口接入指南

> 这篇文档写给「第一次听说 API Key」的同学。
> 读完你应该能：申请到 DeepSeek 的 Key、把它填进软件、看懂常见报错、知道大概花多少钱，
> 以及想换别家模型时该改哪里。
>
> 本文同时适用于 **EXE 版**（免安装，双击 exe 使用）和**源码版**（需要 Python）：
> 填 Key 的位置和界面操作完全一样，只是**配置文件位置不同**——
> EXE 版在 exe 同目录的 `config.json`，源码版在 `xyb/config.json`，文中会分别标注。

---

## 0. 先弄懂 3 个词

| 名词 | 用大白话说 |
| --- | --- |
| **API Key** | 一串类似密码的字符串，相当于你 AI 账户的「付款码」。谁拿到它，就能花你账户里的钱。 |
| **base_url** | AI 服务的「网址前缀」。程序把请求发到这个地址。 |
| **model** | 用哪个模型来写。不同的模型价格、速度、写作水平不一样。 |

本工具默认使用 **DeepSeek** 的 `deepseek-chat` 模型。
DeepSeek 提供「OpenAI 兼容接口」，所以只要服务商也兼容这种格式，换别家模型通常只需要改
`base_url` 和 `model` 两个值（见第 5 节）。

## 1. 申请 DeepSeek API Key（完整步骤）

> 全程在浏览器里操作，大约 3～5 分钟。
> 申请 Key 本身免费，但**生成周志会消耗余额**，所以需要充值（见第 3 节）。

1. 打开 DeepSeek 开放平台：<https://platform.deepseek.com/>
2. 注册或登录。
   - 没有账号：按页面提示用手机号或邮箱注册。
   - 已有账号：直接登录。
   - 如果页面要求实名认证或绑定手机，按提示完成即可。
3. 登录后，看左侧菜单，点击 **「API keys」**。
4. 点击页面上的 **「创建 API key」**（也可能写作 **Create API key**）。
5. 给 Key 起个名字，例如 `xyb-journal`，然后确认创建。
   - 名字只是给你自己看的，随便填。
6. 页面会显示一串以 `sk-` 开头的字符串。点击复制。
   - **这串 Key 只显示这一次。** 关掉页面后就看不到了，只能重新创建一个。
   - 复制后先粘贴到记事本里临时保存，确认**开头结尾没有空格、没有换行**。
7. 回到左侧菜单，找到 **「充值」/「账户充值」** 页面，按提示充值。
   - 最低充值金额、支付方式以官网页面为准。
   - **余额为 0 时，生成周志会报 402（余额不足）。**
8. 把 Key 填进软件后，记得把记事本里的临时记录删掉（见第 6 节）。

> 小提醒：Key 是一串字符，不是你的账号密码。
> 不要把它当成登录密码填到别的网站，也不要在任何群里发。

## 2. 把 Key 填进软件（两种方式，任选一种）

### 方式一：用首次向导或菜单 6（推荐，不用手改文件）

1. 启动程序：**EXE 版**双击 `校友邦周志助手.exe`；**源码版**双击仓库根目录的 `start.bat`。进入主菜单。
2. 第一次使用会自动显示欢迎语和配置向导；以后要修改，输入 `6`，按回车，进入「修改配置」向导。
3. 向导第 1 项是 **`DeepSeek API Key`**。把复制好的 Key 粘贴进去，按回车。
   - 输入时屏幕上**不会显示**你输入的内容，这是正常的。
   - 在 Windows 命令行窗口里，右键一般就是粘贴。
4. 接下来几项（模型名、实习单位、岗位、工作内容、任务、技术栈、字数）如果不想改，直接按回车保持原值。
5. 最后向导会问「要现在测试一下 Key 能不能用吗？」。
   - 输入 `y` 回车：软件会真的发一次很短的请求，显示「连通正常」就说明 Key 可用。
   - 输入 `n` 回车：跳过测试，稍后生成周志时也能验证。

> 第一次启动程序会自动进入欢迎语和配置向导，按提示填 Key 就行，不需要先手动选 6。
> 以后要修改配置，选菜单 `6` 即可。EXE 版和源码版这一步完全相同。

### 方式二：直接编辑配置文件

适合想一次改多项、或者想换别家服务商（改 `base_url`）的同学。

配置文件位置：

- **EXE 版**：exe 同目录的 `config.json`（和 exe 放在一起）；
- **源码版**：仓库里的 `xyb/config.json`。

1. 找到配置文件：
   - EXE 版：打开 exe 所在的文件夹，找到 `config.json`；
   - 源码版：打开仓库里的 `xyb` 文件夹，找到 `config.json`。
   - 右键 `config.json` →「打开方式」→「记事本」。
   - 如果只有 `config.example.json`、没有 `config.json`：先启动一次程序（会自动生成），或者把
     `config.example.json` 复制一份，重命名为 `config.json`，再打开。
2. 找到这一段：

   ```json
   "ai": {
     "base_url": "https://api.deepseek.com/v1",
     "model": "deepseek-chat",
     "api_key": "sk-在这里填你的DeepSeekKey",
     "temperature": 0.8,
     "timeout": 90
   }
   ```

3. 把 `api_key` 引号里的内容整个替换成你的 Key，例如：

   ```json
   "api_key": "sk-你的真实Key",
   ```

   注意：
   - **保留两边英文双引号**。
   - **保留这一行末尾的英文逗号**（如果后面还有字段）。
   - 不要用 Word、写字板等会加格式的软件，用记事本或 VS Code 即可。
   - 保存时编码选 UTF-8（记事本默认就是）。
4. 保存文件，关闭记事本，重新启动程序（EXE 版双击 exe；源码版双击 `start.bat`）。

### 怎么确认填对了

- 菜单 6 里最后一步的「测试 Key」显示「连通正常」。
- 或者直接选菜单 2 生成一篇周志，能正常出正文就说明配置成功。

## 3. 费用与用量估算

- 一篇 300～700 字的周志，提示词加正文合计大约消耗 **1000～2500 tokens**。
  （字数越多、模型越啰嗦，消耗越接近上限。）
- 按 DeepSeek `deepseek-chat` 的公开价格量级，**单篇成本通常在几分钱人民币**；
  一个学期十几到二十篇，合计通常也就是**几毛到一两块钱**的量级。
- 批量补交时按篇数线性累加：补 10 篇大概是单篇的 10 倍。
- 以上只是**量级参考**。模型价格、计费规则、赠送额度随时可能调整，
  **准确价格以 <https://platform.deepseek.com/> 官网的「价格」页面和你的实际账单为准**。
- 建议第一次先充少量金额，生成一两篇确认效果，再决定要不要批量补交。

## 4. 报错对照表

程序会把接口错误翻译成中文提示，并附上服务端返回的信息。
对照下表处理即可。

| 你会看到 | 原因 | 怎么办 |
| --- | --- | --- |
| **401 / 403 鉴权失败** | Key 复制不完整、多了空格或换行、Key 已被删除/过期；也可能是 Key 没有该模型的权限。 | 回到 DeepSeek 后台重新复制完整 Key（从 `sk-` 到结尾），删掉首尾空格；仍不行就删除旧 Key、新建一个；确认 `base_url` 确实是 DeepSeek 的地址，没有把别家的 Key 填进来。 |
| **402 余额不足** | 账户还没充值，或余额已用完。 | 到 DeepSeek 后台「充值」页面充值，到账后重试。 |
| **404 接口地址或模型不存在** | `ai.base_url` 或 `ai.model` 写错；换服务商后只改了模型没改地址。 | DeepSeek 用 `base_url = https://api.deepseek.com/v1`、`model = deepseek-chat`；检查有没有漏掉 `/v1`，也不用自己补 `/chat/completions`（程序会自动拼）。 |
| **429 请求太频繁** | 短时间内连续生成/重试太多次，被服务商限流。 | 等几十秒到几分钟再试；批量补交时不要同时开多个程序窗口。 |
| **请求超时** | 网络慢、代理不稳定，或 `ai.timeout` 设得太小。 | 先确认浏览器能打开 DeepSeek 网站；把配置文件里的 `ai.timeout` 从 `90` 改成 `180` 或更大（EXE 版是 exe 同目录 `config.json`，源码版是 `xyb/config.json`）；使用代理时确认代理对程序生效。 |
| **无法连接到 AI 接口 / 证书错误** | 断网、代理未开启、校园网或公司网络限制、系统时间不对。 | 浏览器访问 <https://platform.deepseek.com/> 验证网络；切换代理状态后重试；校准 Windows 系统时间；换一个网络环境试试。 |
| **返回里没有 choices / 不是合法 JSON** | `base_url` 不是 OpenAI 兼容接口地址，或返回了网页错误页。 | 核对 `base_url` 是否是兼容接口地址（一般以 `/v1` 结尾），不要填成浏览器里打开的网页地址。 |
| **AI 模型返回了空正文** | 偶发的模型输出问题，或 `model` 填成了非对话模型。 | 重新生成一次；持续为空就确认 `model` 是对话模型（DeepSeek 常用 `deepseek-chat`）。 |

> 更详细的排查顺序和登录类问题，见仓库根目录 `README.md` 的「常见问题 FAQ」。

## 5. 想换别家模型怎么办

### 5.1 通用改法

前提：该服务商提供 **OpenAI 兼容接口**（地址形如 `https://.../v1/chat/completions`）。
满足这个前提时，只需要改配置文件（EXE 版：exe 同目录 `config.json`；源码版：`xyb/config.json`）里 `ai` 段的 3 个值：

```json
"ai": {
  "base_url": "服务商的接口地址",
  "model": "模型名称",
  "api_key": "服务商给你的 Key",
  "temperature": 0.8,
  "timeout": 120
}
```

其余配置（`internship`、`style` 等）都不用动。

> 注意：菜单 6 的向导只问 Key、模型名、实习信息和字数，**不问 `base_url`**。
> 换别家服务商时，请用「方式二：直接编辑配置文件」改 `base_url`。

### 5.2 常见服务商参数表

| 服务商 | `base_url` | `model` 示例 | 说明 |
| --- | --- | --- | --- |
| **DeepSeek**（默认） | `https://api.deepseek.com/v1` | `deepseek-chat` | 本工具默认，价格便宜，中文写作够用。 |
| **通义千问**（阿里云百炼 DashScope 兼容模式） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | 在阿里云百炼控制台创建 API Key；`qwen-turbo` 更便宜，模型名以控制台为准。 |
| **智谱 GLM** | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | 在智谱开放平台创建 Key；可用模型以官网为准。 |
| **月之暗面 Kimi** | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | 在 Kimi 开放平台创建 Key；模型名以官网为准。 |
| **本地 Ollama** | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` | 完全在本机跑，不联网、不花钱；先安装 Ollama 并执行 `ollama pull qwen2.5:7b`，保持 Ollama 在后台运行。`api_key` 不能留空，填一个非占位符，例如 `sk-ollama`。 |

不同服务商的 Key 格式不同，不一定是 `sk-` 开头，按官网复制的原样填即可。
但 `api_key` 不能留空，也不能保留示例里的占位文字。

### 5.3 示例：换成通义千问

把配置文件（EXE 版：exe 同目录 `config.json`；源码版：`xyb/config.json`）的 `ai` 段改成：

```json
"ai": {
  "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "model": "qwen-plus",
  "api_key": "sk-你在阿里云百炼创建的Key",
  "temperature": 0.8,
  "timeout": 120
}
```

保存后重新启动程序（EXE 版双击 exe；源码版双击 `start.bat`），选 2 生成一篇试试。

### 5.4 换模型的注意事项

- 不同模型的写作风格和字数控制不一样，可能出现字数不足、夹英文单词等情况。
  先用菜单 4 质检，再决定是否重新生成。
- 本地模型（Ollama）生成速度取决于电脑配置。普通笔记本跑 7B 模型，一篇可能要 1～3 分钟，
  请把 `ai.timeout` 调大（例如 `300`）。
- 有些服务商要求先实名认证或开通付费，按官网提示操作。
- 换模型后，费用按对应服务商的官网价格计算，第 3 节的 DeepSeek 估算不再适用。

## 6. 安全提醒（务必看）

- 你的 Key 只保存在**本机**的配置文件里：EXE 版是 exe 同目录的 `config.json`，源码版是 `xyb/config.json`。
- 源码版仓库的 `.gitignore` 已把 `xyb/config.json`、`chrome-profile/`、`周志记录/`、
  `xyb/qr.png`、`xyb/.pending*.json` 等本地文件排除，正常提交代码不会带上它们；
  EXE 版的这些文件（`config.json`、`chrome-profile\`、`周志记录\` 等）都在 exe 同目录，本来就不在 git 仓库里。
- **不要**做这些事：
  - 把 Key 发到班级群、QQ 群、微信群；
  - 把带 Key 的截图发到社交平台；
  - 把 Key 粘贴到 GitHub Issue、论坛或网盘；
  - 在 `git add -f` 时强行把源码版的 `xyb/config.json` 加进去。
- **怀疑 Key 泄露了怎么办**：
  1. 登录 DeepSeek 后台，进入「API keys」；
  2. 删除旧的 Key（删除后立即失效）；
  3. 创建一个新 Key，按第 2 节重新填进软件；
  4. 如果曾经把 Key 提交到 GitHub，除了换 Key，还要清理仓库历史（或请仓库管理员处理）。
- 程序日志和报错里会对 Key 打码，但把完整终端输出发到网上前，仍建议自己再检查一遍。

## 7. 一页纸总结

1. 打开 <https://platform.deepseek.com/> 注册/登录。
2. 左侧「API keys」→ 创建 → 复制 `sk-` 开头的 Key（只显示一次）。
3. 在「充值」页充值；余额为 0 会报 402。
4. 启动程序（EXE 版双击 exe；源码版双击 `start.bat`）→ 首次向导或菜单 `6` → 粘贴 Key → 保存；或直接改配置文件（EXE 版是 exe 同目录 `config.json`，源码版是 `xyb/config.json`）。
5. 选菜单 `2` 生成一篇；能出正文就说明配好了。
6. 换别家模型：只改 `ai.base_url`、`ai.model`、`ai.api_key`，详见第 5 节。
7. Key 不外发；怀疑泄露就删掉重建。
