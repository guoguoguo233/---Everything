# 校友邦周志助手

> 英文仓库名：`xyb-weekly-journal`

一个运行在 Windows 上的实习周志辅助工具，面向使用「校友邦」（<https://www.xybsyw.com/>）的大学生：
复用你本机 Chrome 的已登录状态，自动读取实习计划、单位、岗位、周次和学校要求，
调用 DeepSeek 生成周志正文，**先给你预览，确认后才提交**，并把已提交内容归档到本地。

不保存校友邦账号密码，不内置任何账号，不绕过平台限制。

## 功能亮点

- **不用记命令**：双击 `install.bat` 安装，双击 `start.bat` 打开数字菜单，按编号操作。
- **复用本机 Chrome 登录态**：不保存账号密码；登录失效时用「校友邦学生版小程序」扫码登录。
- **自动读取实习信息**：实习计划、实习单位、岗位、周次、学校要求的字数和标题格式都会自动获取。
- **调用 DeepSeek（OpenAI 兼容接口）写作**：生成后先在终端预览，输入 `y` 确认才提交。
- **批量补交 + 质检 + 本地归档**：可批量生成历史周、检查字数/英文残留/重复度，并归档到 `周志记录/周志记录.md`。

## ⚠️ 使用前必读

1. **内容必须由你本人核对真实性。** AI 只负责起草和排版。提交前请逐篇核对：写的事情要是你真实做过的，不能编造项目、数据、人名。虚假实习记录可能影响你的成绩和诚信记录。
2. **仅限本人账号使用。** 请只登录你自己的校友邦账号、提交你自己的周志，不要把程序借给同学共用账号，也不要代写他人周志。
3. **遵守你所在学校和实习单位的规定。** 学校是否允许使用 AI 辅助、是否允许补交、格式要求如何，都以你学校的规定和指导老师的要求为准。本工具不承诺「包过」，也不承诺「绝对不被发现」。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 或 Windows 11（64 位） |
| Python | **3.10 或更高版本**。下载页：<https://www.python.org/downloads/windows/> 。安装第一页务必勾选 **Add python.exe to PATH**（新版安装器文字是 `Add python.exe to PATH`），再点 Install Now。装完在 PowerShell 里执行 `python --version` 能看到版本号即可。 |
| 浏览器 | 本机已安装 **Google Chrome**（稳定版）。下载：<https://www.google.com/chrome/> 。程序直接调用你电脑上的 Chrome 复用登录态，不需要另外装浏览器内核。 |
| 网络 | 安装依赖、调用 AI 接口时需要联网；校友邦平台本身也需要能正常访问。 |

> 支持范围：Windows 上的校友邦学生端「实习周志」。其他平台、其他类型的报告不在支持范围内。

## 快速开始

### 第 1 步：下载解压，双击 `install.bat`

1. 在 GitHub 仓库页面点 **Code → Download ZIP** 下载，解压到例如 `D:\xyb-journal`。
2. 双击 `install.bat`。它会自动完成 4 件事：
   - 检查 Python 版本（要求 3.10+；没有 Python 时会尝试用 winget 自动安装 3.12）；
   - 安装 4 个 Python 依赖（只有 requests、playwright、qrcode、pillow；首次约 1～3 分钟，需要联网。**不需要**额外执行 `playwright install` 下载浏览器，程序直接使用本机 Chrome）；
   - 检查本机是否安装了 Google Chrome（没装会提示你先装）；
   - 如果 `xyb/config.json` 不存在，就从 `config.example.json` 复制一份。
3. 看到「**安装完成！**」和「**下一步：双击 start.bat 启动**」后，按任意键关闭窗口。

出现「未检测到 Python」「依赖安装失败」怎么办：看下方 [常见问题 FAQ](#常见问题-faq) 第 4 条。

### 第 2 步：申请并填写 DeepSeek API Key（极简版）

1. 打开 <https://platform.deepseek.com/> ，注册/登录 → 左侧「API keys」→「创建 API key」→ 复制 `sk-` 开头的字符串（**只显示一次**）。
2. 到左侧「充值」页面充值（最低金额以官网为准；余额为 0 会报 402）。
3. 双击 `start.bat`：首次启动会显示欢迎语，按回车后自动进入配置向导，把 Key 粘贴进去即可；以后要修改，选菜单 `6`。

> 完整步骤、费用估算、报错对照表、想换其他模型（通义千问 / 智谱 GLM / Kimi / 本地 Ollama）：
> 见 **[docs/AI接口接入.md](docs/AI接口接入.md)**。

### 第 3 步：登录并写第一篇周志

1. 配置向导保存后，程序会显示「下一步：扫码登录」并自动进入登录检查（以后重新打开程序时，输入 `1` 检查 / 完成登录）。
2. 登录检查会在后台启动 Chrome，并启动本地二维码页面 **<http://127.0.0.1:8765/>**，二维码图片同时保存到 `xyb/qr.png`。
   - 用手机打开 **「校友邦学生版」小程序** → 小程序里的 **扫一扫** → 扫电脑上的二维码 → 手机确认。
   - **最常见的坑：必须用「校友邦学生版小程序」里的扫一扫，不能用微信首页的「+」→ 扫一扫。** 用微信扫会没反应，或者扫出来是一串 JSON。
3. 登录成功后回到主菜单，输入 `2` 回车。程序会显示读取到的实习信息，并生成本周周志。
4. 逐段核对正文。确认没问题按提示输入 `y` 提交；提交成功后会显示「已在校友邦列表中确认」，并把内容写入 `周志记录/周志记录.md`。

> 每一步的详细界面描述见 **[docs/操作指引.md](docs/操作指引.md)**。

## 操作指引

双击 `start.bat` 后进入主菜单，按数字选择功能：

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| `1` | 登录 / 检查登录状态 | 先检查本机登录态；有效则直接通过。失效时会启动二维码页面，用「校友邦学生版小程序」扫码即可。 |
| `2` | 写本周周志 | 自动定位「本周」，读取学校要求并生成正文。会先问你一句本周的真实素材（可留空），然后预览，输入 `y` 才提交。本周已提交过会自动跳过。 |
| `3` | 批量补交历史周 | 先问要补哪些周（如 `1-9`，回车=全部未提交）；逐周生成后保存预览文件，并自动质检；你看完预览、输入 `yes` 确认后才批量提交。 |
| `4` | 质检已生成内容 | 检查菜单 `3` 生成的待提交内容：字数是否达标、是否混入英文单词、周与周之间重复度是否过高，并列出问题。 |
| `5` | 刷新本地归档 | 从校友邦回读已提交的周志，重建 `周志记录/周志记录.md`。只读取，不会修改平台内容。 |
| `6` | 修改配置 | 连续向导，依次修改：AI Key、模型名、实习单位、岗位、主要工作内容、常见任务、技术栈、最少字数、最多字数；最后可测试 Key 是否可用。 |
| `7` | 查看使用说明 | 用系统默认程序打开本 README。 |
| `0` | 退出 | 退出程序。 |

### 产物位置

| 文件 / 目录 | 是什么 |
| --- | --- |
| `周志记录/周志记录.md` | 已提交周志的本地归档（菜单 `2` 提交后追加；菜单 `5` 会从系统回读重写）。 |
| `周志记录/待提交预览_第X-Y周.md` | 菜单 `3` 批量生成的预览文件，**未提交前**先看它。 |

| `xyb/qr.png` | 最近一次生成的登录二维码图片。 |
| `xyb/.pending*.json` | 待提交内容的本地缓存，程序自动管理。 |

## 配置文件说明

配置文件路径：`xyb/config.json`。安装时由 `config.example.json` 自动复制生成，也可以用菜单 `6` 修改。

| 字段 | 示例值 | 含义 |
| --- | --- | --- |
| `ai.api_key` | `sk-...` | AI 服务的 API Key。**只保存在本机，不要外发。** |
| `ai.model` | `deepseek-chat` | 模型名称。 |
| `ai.base_url` | `https://api.deepseek.com/v1` | OpenAI 兼容接口地址。换别家服务商时改这里，见 `docs/AI接口接入.md`。 |
| `ai.temperature` | `0.8` | 生成的随机性，范围 0～2。保持默认即可，调太高更容易写飞。 |
| `ai.timeout` | `90` | 单次请求的超时秒数。网络慢或使用本地模型时可调大（如 `180`、`300`）。 |
| `internship.company` | 空 | 实习单位。**运行时会自动从校友邦读取并覆盖**，一般不用手填。 |
| `internship.position` | 空 | 实习岗位。**运行时会自动读取并覆盖**。 |
| `internship.department` | 空 | 部门，可选。 |
| `internship.work_summary` | 空 | 主要工作内容。运行时会用系统里的岗位职责覆盖。 |
| `internship.common_tasks` | `[]` | 常见日常任务，字符串数组，作为写作素材。 |
| `internship.tech_stack` | `[]` | 用到的技术 / 工具，字符串数组。 |
| `internship.industry` | 空 | 所属行业，可选。 |
| `style.min_words` | `320` | 每篇最少字数。若学校要求更高，程序会自动抬到「学校要求 + 20」。 |
| `style.max_words` | `620` | 每篇最多字数。 |
| `style.tone` | 平实、具体…… | 文风要求，会写进给 AI 的提示词。 |
| `style.format` | 分 3～4 段…… | 段落结构要求。 |
| `style.title_pattern` | `{position}实习周志（第{index}周）` | 标题模板，可用占位符：`{position}` `{company}` `{department}` `{index}` `{startDate}` `{endDate}`。学校有固定标题格式时，程序会尝试自动识别替换。 |
| `record.dir` | `周志记录` | 本地归档目录。 |
| `record.file` | `周志记录.md` | 本地归档文件名。 |
| `zhizhi` | `type: w` 等 | 提交接口内部参数，保持默认，不要修改。 |

注意事项：

- **实习单位和岗位不需要自己填**：程序运行时从校友邦读取真实值并覆盖配置。只有读取不到时，才需要到菜单 `6` 手动补填。
- 修改 JSON 时保留英文双引号、逗号和花括号；写坏了程序会提示「配置文件格式有误」。
- 推荐用菜单 `6` 修改，避免手写 JSON 出错。
- 菜单 `6` 不修改文风（`style.tone`）、段落结构（`style.format`）和标题模板（`style.title_pattern`），要改这三项请直接编辑 `xyb/config.json`。
- 换别家 AI 服务商时菜单 `6` 只能改模型名，还需要手动改 `ai.base_url`，详见 `docs/AI接口接入.md` 第 5 节。

## 进阶用法（可选）

不会用命令行可以跳过本节。菜单能完成日常所有操作，以下命令适合排错或小范围测试。
在仓库根目录打开 PowerShell，然后执行：

```powershell
# 只生成一篇指定周次并预览，不提交
python xyb\run.py --week 8 --dry-run

# 带一句真实素材生成当前周
python xyb\run.py --notes "这周主要在做接口联调，帮同事补了几个测试用例"

# 生成 1-9 周中所有未提交的周，只创建预览文件
python xyb\run.py --gen-batch --weeks 1-9

# 质检上一次批量生成的内容
python xyb\run.py --qc

# 提交上一次批量生成的内容（--yes 会跳过确认，务必先看过预览）
python xyb\run.py --submit-batch --yes

# 重新生成批次里的某一周
python xyb\run.py --regen-week 5

# 单独测试 API Key 是否可用
python xyb\ai_writer.py --check
```

> `--submit-batch --yes` 会直接提交、不再询问，不建议在没看过预览的情况下使用。

## 常见问题 FAQ

### 1. 二维码扫了没反应，或者扫出来是一串 JSON

**症状**：用手机扫电脑上的二维码，手机没有任何跳转；或者扫出一段类似
`{"code":"...","key":"..."}` 的文字。

**原因**：用了微信 / 支付宝的普通扫一扫。这个二维码不是网址，而是校友邦小程序专用的登录凭证 JSON，
只有「校友邦学生版小程序」能识别。

**解决**：
1. 打开微信，搜索并进入 **「校友邦学生版」小程序**（不是微信首页的扫一扫）。
2. 在小程序里找到 **扫一扫**，扫电脑上 `http://127.0.0.1:8765/` 页面显示的二维码。
3. 二维码会自动更新（页面每 5 秒刷新），扫页面上当前显示的那张即可。
4. 仍不行：关掉程序重新双击 `start.bat`，再选 `1` 试一次；确认手机网络正常。

### 2. 提示「701 安全校验已升级」

**症状**：终端或接口返回里出现 `701`，提示安全校验升级 / 校验失败。

**原因**：校友邦后端的签名校验凭证过期了，程序缓存的页面凭证需要刷新。这不是你操作错了，
平台更新后也可能出现。

**解决**：
- 程序检测到 `701` 会**自动刷新页面、重新加载签名模块并重试**，大多数情况你只会看到日志闪过，不需要操作。
- 连续多次失败：关闭窗口，重新双击 `start.bat`；确认用 Chrome 能正常打开 <https://www.xybsyw.com/personal/> 。
- 还是不行：删除 `xyb/.session.json`（只是缓存凭证，删掉会自动重建），再试一次。
- 仍然报 `701` 且无法恢复，很可能是站点改版。记录完整报错去仓库提 Issue，不要反复强行提交。

### 3. DeepSeek 报 401 / 402 / 429 / 超时

**症状**：生成周志时终端提示「AI 接口鉴权失败」「余额不足」「请求太频繁」或「请求超时」。

**原因**：Key 无效、账户没充值、触发限流，或者网络 / `ai.timeout` 配置不合适。

**解决**：

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| **401 / 403 鉴权失败** | Key 复制不全、有空格、已删除或过期。 | 重新复制完整 `sk-` Key，删掉首尾空格；仍不行就删除旧 Key、新建一个。 |
| **402 余额不足** | 账户没充值或余额用完。 | 到 DeepSeek 后台充值。 |
| **429 请求太频繁** | 短时间生成/重试太多，被限流。 | 等几十秒到几分钟再试，不要同时开多个窗口。 |
| **请求超时** | 网络慢、代理问题，或 `ai.timeout` 太小。 | 确认网络正常；把 `xyb/config.json` 的 `ai.timeout` 改成 `180` 或更大。 |

完整的「报错 → 原因 → 解决」对照表见 **[docs/AI接口接入.md](docs/AI接口接入.md) 第 4 节**。

### 4. 提示未检测到 Python，或提示 `python` 不是内部或外部命令

**症状**：`install.bat` 窗口提示 `Python not found` /「未检测到 Python」；或在命令行执行 `python` 时提示
「'python' 不是内部或外部命令」。

**原因**：电脑没有安装 Python，或者安装时没有勾选把 Python 加入 PATH。

**解决**：
1. 打开 <https://www.python.org/downloads/windows/> ，下载 Python 3.10 以上的 Windows 安装包（64-bit）。
2. 运行安装包，第一页底部**勾选 `Add python.exe to PATH`**，再点 `Install Now`。
3. 安装完成后重启电脑（或至少关掉所有命令行窗口）。
4. 重新双击 `install.bat`。它检测不到 Python 时也会尝试用 winget 自动安装 3.12，
   如果自动安装成功，按提示关闭窗口再双击一次。
5. 仍不行：打开 PowerShell 输入 `python --version`，确认能显示 `Python 3.x.x`。

### 5. 启动时提示找不到 Chrome / 环境检查未通过

**症状**：双击 `start.bat` 后菜单没出现，而是列出「没有找到 Google Chrome」「缺少依赖」等 `✗` 项，
并让你先运行 `install.bat`。

**原因**：本机没安装 Google Chrome，或装的是绿色版 / 便携版 / 位置异常；也可能是依赖没装好。

**解决**：
1. 到 <https://www.google.com/chrome/> 下载并安装正式版 Chrome，启动一次确认能打开网页。
2. 重新双击 `install.bat`，确认 4 个步骤都通过。
3. 再双击 `start.bat`。如果仍提示找不到 Chrome，重启电脑后重试；
   绿色版 / 修改版 Chrome 可能无法被识别，请换用官方安装版。

### 6. 登录态多久失效？每次都要扫码吗？

**症状**：不确定登录状态能保持多久，担心每次打开都要重新扫码。

**原因**：登录态保存在本机 `chrome-profile/` 目录里，程序会复用它；平台的登录凭证会过期，
所以不是永久有效。

**解决**：正常每周用一次，登录态通常可以保持很多天，不需要每次扫码。
需要重新扫码的情况：长时间不用、在校友邦网页端主动退出、清除了浏览器数据、
删除了 `chrome-profile/`，或者平台调整了登录策略。重新扫码时选菜单 `1` 即可。

程序不会保存你的校友邦账号密码，扫码是唯一的登录方式。

### 7. 会不会重复提交同一周？

**症状**：担心同一周被提交两次，产生两条重复记录。

**原因**：程序在写本周周志前会读取该周在系统里的状态，已经有提交记录的周会跳过。

**解决**：正常使用不会重复。已经有提交记录的周会提示「这篇已提交过，跳过」；
批量补交也只处理「系统显示未提交」的周。

注意：
- 不要同时开两个程序窗口操作同一周；
- 如果你已经在校友邦网页端手动提交过，程序会把它当作已提交而跳过；
- 如果提交时网络异常、你不确定系统是否收到，**先去校友邦列表确认**，不要立刻反复提交。

### 8. 历史周能不能补交？

**症状**：前面几周忘了写，想用工具一次补回来。

**原因**：工具能处理系统里仍显示「未提交」的历史周，但学校是否允许补交由学校规定，工具无法保证。

**解决**：技术上能生成和提交，但不代表学校允许。补交是否计分、是否扣分、是否需要老师批准，
以你学校的实习管理规定和指导老师要求为准。补交前先问清楚老师或查看学院通知；
如果学校不允许补交，请不要使用本工具的批量补交功能。

### 9. 老师退回修改后怎么办？

**症状**：老师把某周周志退回了，不知道该怎么改、能不能让工具重新提交。

**原因**：老师退回后，系统里这一周通常已经有提交记录（只是状态变成退回 / 需修改）。
程序读取到「已有记录」会跳过，不会自动覆盖，这是为了避免产生重复周志。

**解决**：登录校友邦网页端或小程序，在老师退回的那一篇上按意见修改后重新提交；
如果系统支持删除后重写，也可以删除后重新用菜单 `2` 生成（生成后务必核对）。
操作前不确定的话，直接问指导老师或学校教务。

### 10. 生成字数不够 / 有英文单词混入

**症状**：预览时字数低于学校要求，或正文里夹着不相关的英文单词。

**原因**：模型输出有波动；或配置的字数下限偏低；或技术栈里的英文被写进正文。

**解决**：
- 菜单 `4` 可以质检菜单 `3` 批量生成的内容：会检查字数、英文残留、周与周之间的重复度。
  单篇提交前的质检靠你自己读一遍。
- 字数不够：到菜单 `6` 适当调大「每篇最少字数」，重新生成一次。
- 英文残留：重新生成通常能换一版；如果英文是 `Python`、`Java`、`C++` 这类真实技术名词，属于正常内容。
- 质检会把可疑的英文单词列出来，人工判断一下即可，不代表一定有问题。
- 反复生成仍不满意：到校友邦网页端手动修改后提交，不要为了凑字数提交空话。

### 11. 双击 `start.bat` 窗口一闪而过

**症状**：双击后黑色窗口一闪就关闭，菜单没出现。

**原因**：通常是 Python / 依赖 / Chrome 环境没准备好，程序启动失败；也可能是脚本被安全软件拦截。

**解决**：
1. 先重新双击 `install.bat`，确认 4 个步骤全部成功。
2. 右键 `start.bat` →「在终端中打开」（Windows 11）或打开 PowerShell 后执行 `.\start.bat`，
   这样能看到具体报错，再对照本 FAQ 处理。
3. 检查安全软件是否拦截了批处理或 Chrome，必要时把仓库目录加入信任。
4. 仍不行，记录报错文字到仓库提 Issue。

### 12. 提交后在周志列表里看不到

**症状**：终端提示提交成功，但校友邦页面上没看到这一周。

**原因**：通常是页面缓存 / 列表同步延迟；也可能是浏览器里登录的账号和程序使用的账号不一致。

**解决**：
1. 等 1～3 分钟，刷新校友邦页面或小程序列表。
2. 用菜单 `5` 从系统回读归档，看这一篇是否已经在系统里。
3. 确认程序显示的「登录身份」和你要提交的账号是同一个人。
4. **不要立刻反复提交**。长时间确实没有，再检查网络或向老师确认，必要时提 Issue。

### 13. 我的信息会被发到哪里？

**症状**：担心周志内容、实习信息、API Key 被上传到不明服务器。

**原因**：本工具需要调用 AI 服务商生成正文，需要访问校友邦读写周志，因此会产生两次外部通信。

**解决 / 说明**：

- **AI 生成时**：程序会把实习单位、岗位、周次、学校要求的字数 / 标题格式，以及你在菜单 `2`
  里填的「本周真实素材」，发送给你配置的 AI 服务商（默认是 DeepSeek），用于生成正文。
  这些内容会按该服务商的隐私政策处理。
- **校友邦操作**：读取实习信息和提交周志，都在你本机安装的 Chrome 里直接访问校友邦完成。
- **本地保存**：API Key、登录态、本地归档都只存在你的电脑上，并已被 `.gitignore` 排除。
- 本项目没有开发者服务器，不会收集、上传你的数据。
- 如果你介意把实习信息发给 AI 服务商，请不要使用本工具，或改用本地模型（见 `docs/AI接口接入.md` 第 5 节）。
