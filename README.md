# 校友邦周志助手

> 英文仓库名：`xyb-weekly-journal`

一个运行在 Windows 上的实习周志辅助工具，面向使用「校友邦」（<https://www.xybsyw.com/>）的大学生：
复用你本机 Chrome 的已登录状态，自动读取实习计划、单位、岗位、周次和学校要求，
调用 DeepSeek 生成周志正文，**先给你预览，确认后才提交**，并把已提交内容归档到本地。

不保存校友邦账号密码，不内置任何账号，不绕过平台限制。

> **普通用户请直接下载 EXE，不用安装 Python。**
> 方式 1（推荐）：打开本仓库的 **Releases** 页面 → 下载 `校友邦周志助手.exe`（单文件，约 55MB）
> 方式 2：在仓库文件列表里点击根目录的 **`校友邦周志助手.exe`** → 右上角 **Download raw file** 下载
> → 放到一个有写权限的文件夹（如 `D:\周志助手\`）→ 双击运行，按首次向导填 Key、扫码登录即可。
>
> 源码版（需要 Python，双击 `install.bat` / `start.bat`）继续保留，适合开发者、想自己改代码的同学，
> 以及 EXE 被杀毒软件拦截时的备选。两种方式打开后的界面完全一样，区别只在「怎么启动」和「数据放在哪」。

## 功能亮点

- **两种用法，双击即用**：普通用户下载 Releases 页的免安装 EXE，双击运行；开发者下载源码后双击 `install.bat` 安装、双击 `start.bat` 启动。两种方式进入同一个数字菜单，按编号操作。
- **便携免安装**：EXE 版的数据（配置、登录态、归档）都放在 exe 同目录，换电脑时把整个文件夹拷走即可保留。
- **复用本机 Chrome 登录态**：不保存账号密码；登录失效时用「校友邦学生版小程序」扫码登录。
- **自动读取实习信息**：实习计划、实习单位、岗位、周次、学校要求的字数和标题格式都会自动获取。
- **调用 DeepSeek（OpenAI 兼容接口）写作**：生成后先在终端预览，输入 `y` 确认才提交。
- **批量补交 + 质检 + 本地归档**：可批量生成历史周、检查字数/英文残留/重复度，并归档到 `周志记录/周志记录.md`。

## ⚠️ 使用前必读

1. **内容必须由你本人核对真实性。** AI 只负责起草和排版。提交前请逐篇核对：写的事情要是你真实做过的，不能编造项目、数据、人名。虚假实习记录可能影响你的成绩和诚信记录。
2. **仅限本人账号使用。** 请只登录你自己的校友邦账号、提交你自己的周志，不要把程序借给同学共用账号，也不要代写他人周志。
3. **遵守你所在学校和实习单位的规定。** 学校是否允许使用 AI 辅助、是否允许补交、格式要求如何，都以你学校的规定和指导老师的要求为准。本工具不承诺「包过」，也不承诺「绝对不被发现」。

## 快速开始

两种方式的区别只在「程序怎么启动」；启动后的界面和菜单操作完全一样。

### 方式一：EXE 版（3 步，推荐普通用户）

1. **下载 exe**（两种方式任选）：
   - **Releases 页（推荐）**：打开本仓库的 **Releases** 页面，在最新版本的 Assets 里下载 `校友邦周志助手.exe`（单文件，约 55MB）；
   - **仓库内直接下载**：在仓库文件列表点击根目录的 `校友邦周志助手.exe`，再点右上角 **Download raw file**。
   - 把 exe 放到一个**有写权限的普通文件夹**，例如 `D:\周志助手\`。**不要**放 `C:\Program Files`（没有写权限，配置和归档会存不下来）。
   - 不需要安装、不需要解压，也不用装 Python。
2. **双击 exe 运行**：首次启动时单文件 EXE 要先自解压，**通常 5～10 秒才出现窗口（杀毒软件扫描时可能更久），这是正常的**，不要以为卡死而反复双击。
   - 如果被 Windows Defender / 360 / 火绒等杀毒软件拦截，见下方「EXE 版注意事项」和 FAQ 第 13 条。
   - 出现欢迎语后按回车，进入配置向导。
3. **首次按向导填 Key 并扫码登录**：
   1. 还没有 API Key 的，先按 **[docs/AI接口接入.md](docs/AI接口接入.md) 第 1 节**申请 `sk-` 开头的 Key（约 3～5 分钟，需要少量充值；建议在双击 exe 之前准备好）。
   2. 配置向导第 1 项粘贴 Key；其余项（模型名、单位、岗位、字数等）可以直接回车保持默认；最后问「测试 Key」时输入 `y`。
   3. 向导保存后程序自动进入扫码登录：用浏览器打开 <http://127.0.0.1:8765/>，用手机 **「校友邦学生版」小程序 → 扫一扫** 扫码（**不能**直接用微信扫一扫）。
   4. 登录成功后回到主菜单，输入 `2` 回车，生成本周周志；核对无误输入 `y` 提交。

> 更细的分步说明（含每一步会看到什么）见 **[docs/操作指引.md](docs/操作指引.md) 第一节**。
> 费用估算、报错对照表、想换其他模型（通义千问 / 智谱 GLM / Kimi / 本地 Ollama）：见 **[docs/AI接口接入.md](docs/AI接口接入.md)**。

### 方式二：源码版（3 步，开发者 / EXE 被拦截时的备选）

1. **下载源码并双击 `install.bat`**：在 GitHub 仓库页面点 **Code → Download ZIP** 下载，解压到例如 `D:\xyb-journal`，双击 `install.bat`。它会自动完成 4 件事：
   - 检查 Python 版本（要求 3.10+；没有 Python 时会尝试用 winget 自动安装 3.12）；
   - 安装 4 个 Python 依赖（只有 requests、playwright、qrcode、pillow；首次约 1～3 分钟，需要联网。**不需要**额外执行 `playwright install` 下载浏览器，程序直接使用本机 Chrome）；
   - 检查本机是否安装了 Google Chrome（没装会提示你先装）；
   - 如果 `xyb/config.json` 不存在，就从 `config.example.json` 复制一份。

   看到「**安装完成！**」和「**下一步：双击 start.bat 启动**」后，按任意键关闭窗口。出现「未检测到 Python」「依赖安装失败」怎么办：看下方 [常见问题 FAQ](#常见问题-faq) 第 4 条。
2. **申请并准备 DeepSeek API Key**：打开 <https://platform.deepseek.com/> ，注册/登录 → 左侧「API keys」→「创建 API key」→ 复制 `sk-` 开头的字符串（**只显示一次**）；到左侧「充值」页面充值（最低金额以官网为准；余额为 0 会报 402）。
3. **双击 `start.bat` 启动**：首次启动会显示欢迎语，按回车后自动进入配置向导，把 Key 粘贴进去；随后自动进入扫码登录（扫码方式和 EXE 版第 3 步一样）。登录后回主菜单选 `2` 写第一篇。以后要修改配置，选菜单 `6`。

> 每一步的详细界面描述见 **[docs/操作指引.md](docs/操作指引.md)**。

## EXE 版注意事项

1. **数据都放在 exe 同目录（便携版）**：运行后会在 exe 旁边生成
   `config.json`（配置，含 API Key）、`chrome-profile\`（登录态）、`周志记录\`（归档）、
   `qr.png`（最近一次登录二维码），以及 `.session.json`、`.pending*.json` 等本地缓存。
   **换电脑、换文件夹、重装系统前，把整个文件夹（exe + 这些文件）一起拷走**，登录态和归档都会保留；只拷 exe 不会带走数据。
2. **不要放在没有写权限的目录**：`C:\Program Files`、`C:\Program Files (x86)`、`C:\Windows` 等目录普通用户写不进去，会导致配置保存失败、登录态丢失。放在 `D:\周志助手\`、桌面新建的文件夹这类普通位置即可。
3. **首次启动慢几秒是正常的**：单文件 EXE 启动时要先解压自身，第一次通常 5～10 秒（杀毒软件扫描时可能更久）。窗口没出来时**不要反复双击、不要强制结束**，等半分钟；超过 1 分钟仍没反应，看 FAQ 第 13 条。
4. **杀毒软件误报**：用 PyInstaller 打包的单文件 EXE 经常被 Windows Defender、360、火绒等误报为「可疑程序 / 木马」。这是打包工具导致的**常见误报**，不是真的有病毒：本项目源码完全公开，你可以自己下载源码、用 `build_exe.py` 重新打包验证。被拦截时可以：
   - 在弹窗里选择「允许运行 / 保留此文件 / 添加到信任区」（不同软件措辞不同），或把 exe 所在文件夹加入白名单；
   - 或者改用上面的**源码版**（需要 Python）；
   - 拿不准时可以把文件上传到 <https://www.virustotal.com/> 看多引擎检测结果，但注意「几个引擎报毒」对这类单文件 EXE 很常见。
5. **查看使用说明**：菜单 `7` 打开的是打包进 EXE 的 README 副本，内容与本仓库 README 一致；打不开时直接在本仓库页面看。
6. **EXE 版与源码版界面完全一样**：同一个数字菜单、同一套「生成 → 预览 → 确认 → 提交 → 归档」流程；区别只在「怎么启动」和「数据放在哪」。
7. **遇到问题想反馈**：先看下方 [常见问题 FAQ](#常见问题-faq)；确认是程序问题时，到 GitHub 仓库提 Issue，附上报错文字和复现步骤，**发之前删掉 API Key、姓名、学号、学校、单位等个人信息**。

## 操作指引

启动程序后进入主菜单，按数字选择功能：

> **启动方式**：EXE 版 = 双击 `校友邦周志助手.exe`；源码版 = 双击 `start.bat`。
> 两种方式打开后的界面完全一样，下面是同一个数字菜单。菜单顶部会显示：
> **登录状态**（已登录会显示姓名和学校；未登录会提示去扫码）、**AI Key 状态**、**配置文件路径**、**运行方式**（EXE 免安装版 / 源码版）。排错时先看这几行。

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| `1` | 登录 / 检查登录状态 | 先检查本机登录态；有效则直接通过。失效时会启动二维码页面，用「校友邦学生版小程序」扫码即可。登录成功后会回来刷新顶部状态。 |
| `2` | 写本周周志 | 自动定位「本周」，读取学校要求并生成正文。可以选填本周真实素材；生成后会**自动打开预览文件**给你看，回到窗口可选：`y` 提交、`m` 输入修改意见让 AI 重写（可反复改）、`n` 放弃。本周已提交过会自动跳过。 |
| `3` | 批量补交历史周 | 先问要补哪些周（如 `1-9`，回车=全部未提交）；逐周生成后保存预览文件，并自动质检；你看完预览、输入 `yes` 确认后才批量提交。 |
| `4` | 质检已生成内容 | 检查菜单 `3` 生成的待提交内容：字数是否达标、是否混入英文单词、周与周之间重复度是否过高，并列出问题。 |
| `5` | 刷新本地归档 | 从校友邦回读已提交的周志，重建 `周志记录/周志记录.md`，并刷新顶部登录状态。只读取，不会修改平台内容。 |
| `6` | 修改配置 | 连续向导，依次修改：AI Key、模型名、实习单位、岗位、主要工作内容、常见任务、技术栈、最少字数、最多字数；最后可测试 Key 是否可用。 |
| `7` | 查看使用说明 | 先在窗口内打印使用要点（登录/写周志/批量补交/归档/改配置/排错），再问你是否用默认程序打开完整 README。即使文件打不开，也能在窗口里看到关键步骤。 |
| `0` | 退出 | 退出程序。 |

## 配置文件说明

配置文件路径：**源码版**是 `xyb/config.json`；**EXE 版**是 **exe 同目录的 `config.json`**。首次启动/安装时由 `config.example.json` 自动复制生成，也可以用菜单 `6` 修改。

| 字段 | 示例值 | 含义 |
| --- | --- | --- |
| `ai.api_key` | `sk-...` | AI 服务的 API Key。**只保存在本机，不要外发。** |
| `ai.model` | `deepseek-chat` | 模型名称。 |
| `ai.base_url` | `https://api.deepseek.com/v1` | OpenAI 兼容接口地址。换别家服务商时改这里，见 `docs/AI接口接入.md`。 |
| `ai.temperature` | `0.8` | 生成的随机性，范围 0～2。保持默认即可，调太高更容易写飞。 |
| `ai.timeout` | `90` | 单次请求的超时秒数。网络慢或使用本地模型时可调大（如 `180`、`300`）。 |
| `internship.company` | 空 | 实习单位。**运行时会自动从校友邦读取并覆盖**，一般不用手填。 |
| `internship.position` | 空 | 实习岗位。**运行时会自动读取并覆盖**。 |
| `internship.department` | 空 | 部门，可选。 |
| `internship.work_summary` | 空 | 主要工作内容。运行时会用系统里的岗位职责覆盖。 |
| `internship.common_tasks` | `[]` | 常见日常任务，字符串数组，作为写作素材。 |
| `internship.tech_stack` | `[]` | 用到的技术 / 工具，字符串数组。 |
| `internship.industry` | 空 | 所属行业，可选。 |
| `style.min_words` | `320` | 每篇最少字数。若学校要求更高，程序会自动抬到「学校要求 + 20」。 |
| `style.max_words` | `620` | 每篇最多字数。 |
| `style.tone` | 平实、具体…… | 文风要求，会写进给 AI 的提示词。 |
| `style.format` | 分 3～4 段…… | 段落结构要求。 |
| `style.title_pattern` | `{position}实习周志（第{index}周）` | 标题模板，可用占位符：`{position}` `{company}` `{department}` `{index}` `{startDate}` `{endDate}`。学校有固定标题格式时，程序会尝试自动识别替换。 |
| `record.dir` | `周志记录` | 本地归档目录。 |
| `record.file` | `周志记录.md` | 本地归档文件名。 |
| `zhizhi` | `type: w` 等 | 提交接口内部参数，保持默认，不要修改。 |

注意事项：

- **实习单位和岗位不需要自己填**：程序运行时从校友邦读取真实值并覆盖配置。只有读取不到时，才需要到菜单 `6` 手动补填。
- 修改 JSON 时保留英文双引号、逗号和花括号；写坏了程序会提示「配置文件格式有误」。
- 推荐用菜单 `6` 修改，避免手写 JSON 出错。
- 菜单 `6` 不修改文风（`style.tone`）、段落结构（`style.format`）和标题模板（`style.title_pattern`），要改这三项请直接编辑配置文件（源码版 `xyb/config.json`；EXE 版 exe 同目录的 `config.json`）。
- 换别家 AI 服务商时菜单 `6` 只能改模型名，还需要手动改 `ai.base_url`，详见 `docs/AI接口接入.md` 第 5 节。

## 进阶用法（可选，仅源码版）

下面列的是源码版的 Python 命令，EXE 用户不需要（EXE 版自带的 `--check` / `--version` 排错参数见 FAQ 第 16 条）。
不会用命令行可以跳过本节。菜单能完成日常所有操作，以下命令适合排错或小范围测试。
在仓库根目录打开 PowerShell，然后执行：

```powershell
# 只生成一篇指定周次并预览，不提交
python xyb\run.py --week 8 --dry-run

# 带一句真实素材生成当前周
python xyb\run.py --notes "这周主要在做接口联调，帮同事补了几个测试用例"

# 生成 1-9 周中所有未提交的周，只创建预览文件
python xyb\run.py --gen-batch --weeks 1-9

# 质检上一次批量生成的内容
python xyb\run.py --qc

# 提交上一次批量生成的内容（--yes 会跳过确认，务必先看过预览）
python xyb\run.py --submit-batch --yes

# 重新生成批次里的某一周
python xyb\run.py --regen-week 5

# 单独测试 API Key 是否可用
python xyb\ai_writer.py --check

# 环境自检：打印运行方式、程序目录、配置文件、Key、Chrome/依赖、登录状态（约 5 秒）
python xyb\cli.py --check

# 只打印版本号
python xyb\cli.py --version

# 开发者：自己打包单文件 EXE（需先 pip install pyinstaller，产物在 dist\校友邦周志助手.exe）
python build_exe.py
```

> `--submit-batch --yes` 会直接提交、不再询问，不建议在没看过预览的情况下使用。

## 常见问题 FAQ

> **遇到任何异常，先跑一次「环境自检」**：EXE 版在 exe 所在文件夹的地址栏输入 `cmd` 回车，执行
> `"校友邦周志助手.exe" --check`；源码版执行 `python xyb\cli.py --check`。
> 约 5 秒就会打印运行方式、程序目录、配置文件、AI Key、模型、Chrome / 依赖和登录状态，
> 反馈问题时把这份输出一起贴上，排查会快很多。详见 FAQ 第 16 条。

### 1. 二维码扫了没反应，或者扫出来是一串 JSON

**症状**：用手机扫电脑上的二维码，手机没有任何跳转；或者扫出一段类似
`{"code":"...","key":"..."}` 的文字。

**原因**：用了微信 / 支付宝的普通扫一扫。这个二维码不是网址，而是校友邦小程序专用的登录凭证 JSON，
只有「校友邦学生版小程序」能识别。

**解决**：
1. 打开微信，搜索并进入 **「校友邦学生版」小程序**（不是微信首页的扫一扫）。
2. 在小程序里找到 **扫一扫**，扫电脑上 `http://127.0.0.1:8765/` 页面显示的二维码。
3. 二维码会自动更新（页面每 5 秒刷新），扫页面上当前显示的那张即可。
4. 仍不行：关掉程序重新启动（EXE 双击 exe；源码版双击 `start.bat`），再选 `1` 试一次；确认手机网络正常。

### 2. 提示「701 安全校验已升级」

**症状**：终端或接口返回里出现 `701`，提示安全校验升级 / 校验失败。

**原因**：校友邦后端的签名校验凭证过期了，程序缓存的页面凭证需要刷新。这不是你操作错了，
平台更新后也可能出现。

**解决**：
- 程序检测到 `701` 会**自动刷新页面、重新加载签名模块并重试**，大多数情况你只会看到日志闪过，不需要操作。
- 连续多次失败：关闭窗口，重新启动程序（EXE 双击 exe；源码版双击 `start.bat`）；确认用 Chrome 能正常打开 <https://www.xybsyw.com/personal/> 。
- 还是不行：删除登录缓存 `.session.json`（源码版在 `xyb\` 下，EXE 版在 exe 同目录；只是缓存凭证，删掉会自动重建），再试一次。
- 仍然报 `701` 且无法恢复，很可能是站点改版。记录完整报错去仓库提 Issue，不要反复强行提交。

### 3. DeepSeek 报 401 / 402 / 429 / 超时

**症状**：生成周志时终端提示「AI 接口鉴权失败」「余额不足」「请求太频繁」或「请求超时」。

**原因**：Key 无效、账户没充值、触发限流，或者网络 / `ai.timeout` 配置不合适。

**解决**：

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| **401 / 403 鉴权失败** | Key 复制不全、有空格、已删除或过期。 | 重新复制完整 `sk-` Key，删掉首尾空格；仍不行就删除旧 Key、新建一个。 |
| **402 余额不足** | 账户没充值或余额用完。 | 到 DeepSeek 后台充值。 |
| **429 请求太频繁** | 短时间生成/重试太多，被限流。 | 等几十秒到几分钟再试，不要同时开多个窗口。 |
| **请求超时** | 网络慢、代理问题，或 `ai.timeout` 太小。 | 确认网络正常；把配置文件里的 `ai.timeout` 改成 `180` 或更大（EXE 版配置文件是 exe 同目录的 `config.json`，源码版是 `xyb/config.json`）。 |

完整的「报错 → 原因 → 解决」对照表见 **[docs/AI接口接入.md](docs/AI接口接入.md) 第 4 节**。

### 4. 提示未检测到 Python，或提示 `python` 不是内部或外部命令

> 本条目只适用于**源码版**。EXE 版已内置运行环境，不需要安装 Python，不会遇到这个问题。

**症状**：`install.bat` 窗口提示 `Python not found` /「未检测到 Python」；或在命令行执行 `python` 时提示
「'python' 不是内部或外部命令」。

**原因**：电脑没有安装 Python，或者安装时没有勾选把 Python 加入 PATH。

**解决**：
1. 打开 <https://www.python.org/downloads/windows/> ，下载 Python 3.10 以上的 Windows 安装包（64-bit）。
2. 运行安装包，第一页底部**勾选 `Add python.exe to PATH`**，再点 `Install Now`。
3. 安装完成后重启电脑（或至少关掉所有命令行窗口）。
4. 重新双击 `install.bat`。它检测不到 Python 时也会尝试用 winget 自动安装 3.12，
   如果自动安装成功，按提示关闭窗口再双击一次。
5. 仍不行：打开 PowerShell 输入 `python --version`，确认能显示 `Python 3.x.x`。

### 5. 启动时提示找不到 Chrome / 环境检查未通过

**症状**：双击 `start.bat`（源码版）或 exe（EXE 版）后菜单没出现，而是列出「没有找到 Google Chrome」「缺少依赖」等 `✗` 项。

**原因**：本机没安装 Google Chrome，或装的是绿色版 / 便携版 / 位置异常；源码版还可能是依赖没装好。

**解决**：
1. 到 <https://www.google.com/chrome/> 下载并安装正式版 Chrome，启动一次确认能打开网页。
2. 源码版：重新双击 `install.bat`，确认 4 个步骤都通过；EXE 版：关闭程序后重新双击 exe。
3. 如果仍提示找不到 Chrome，重启电脑后重试；绿色版 / 修改版 Chrome 可能无法被识别，请换用官方安装版。

### 6. 登录态多久失效？每次都要扫码吗？

**症状**：不确定登录状态能保持多久，担心每次打开都要重新扫码。

**原因**：登录态保存在本机 `chrome-profile\` 目录里（源码版在仓库根目录，EXE 版在 exe 同目录），程序会复用它；平台的登录凭证会过期，
所以不是永久有效。

**解决**：正常每周用一次，登录态通常可以保持很多天，不需要每次扫码。
需要重新扫码的情况：长时间不用、在校友邦网页端主动退出、清除了浏览器数据、
删除了 `chrome-profile/`，或者平台调整了登录策略。重新扫码时选菜单 `1` 即可。

程序不会保存你的校友邦账号密码，扫码是唯一的登录方式。

### 7. 会不会重复提交同一周？

**症状**：担心同一周被提交两次，产生两条重复记录。

**原因**：程序在写本周周志前会读取该周在系统里的状态，已经有提交记录的周会跳过。

**解决**：正常使用不会重复。已经有提交记录的周会提示「这篇已提交过，跳过」；
批量补交也只处理「系统显示未提交」的周。

注意：
- 不要同时开两个程序窗口操作同一周；
- 如果你已经在校友邦网页端手动提交过，程序会把它当作已提交而跳过；
- 如果提交时网络异常、你不确定系统是否收到，**先去校友邦列表确认**，不要立刻反复提交。

### 8. 历史周能不能补交？

**症状**：前面几周忘了写，想用工具一次补回来。

**原因**：工具能处理系统里仍显示「未提交」的历史周，但学校是否允许补交由学校规定，工具无法保证。

**解决**：技术上能生成和提交，但不代表学校允许。补交是否计分、是否扣分、是否需要老师批准，
以你学校的实习管理规定和指导老师要求为准。补交前先问清楚老师或查看学院通知；
如果学校不允许补交，请不要使用本工具的批量补交功能。

### 9. 老师退回修改后怎么办？

**症状**：老师把某周周志退回了，不知道该怎么改、能不能让工具重新提交。

**原因**：老师退回后，系统里这一周通常已经有提交记录（只是状态变成退回 / 需修改）。
程序读取到「已有记录」会跳过，不会自动覆盖，这是为了避免产生重复周志。

**解决**：登录校友邦网页端或小程序，在老师退回的那一篇上按意见修改后重新提交；
如果系统支持删除后重写，也可以删除后重新用菜单 `2` 生成（生成后务必核对）。
操作前不确定的话，直接问指导老师或学校教务。

### 10. 生成字数不够 / 有英文单词混入

**症状**：预览时字数低于学校要求，或正文里夹着不相关的英文单词。

**原因**：模型输出有波动；或配置的字数下限偏低；或技术栈里的英文被写进正文。

**解决**：
- 菜单 `4` 可以质检菜单 `3` 批量生成的内容：会检查字数、英文残留、周与周之间的重复度。
  单篇提交前的质检靠你自己读一遍。
- 字数不够：到菜单 `6` 适当调大「每篇最少字数」，重新生成一次。
- 英文残留：重新生成通常能换一版；如果英文是 `Python`、`Java`、`C++` 这类真实技术名词，属于正常内容。
- 质检会把可疑的英文单词列出来，人工判断一下即可，不代表一定有问题。
- 反复生成仍不满意：到校友邦网页端手动修改后提交，不要为了凑字数提交空话。

### 11. 源码版双击 `start.bat` 窗口一闪而过

**症状**：双击后黑色窗口一闪就关闭，菜单没出现。

**原因**：通常是 Python / 依赖 / Chrome 环境没准备好，程序启动失败；也可能是脚本被安全软件拦截。

**解决**：
1. 先重新双击 `install.bat`，确认 4 个步骤全部成功。
2. 右键 `start.bat` →「在终端中打开」（Windows 11）或打开 PowerShell 后执行 `.\start.bat`，
   这样能看到具体报错，再对照本 FAQ 处理。
3. 检查安全软件是否拦截了批处理或 Chrome，必要时把仓库目录加入信任。
4. 仍不行，记录报错文字到仓库提 Issue。

> EXE 版双击后没反应、或被杀毒软件拦截，看下面第 13 条。

### 12. 提交后在周志列表里看不到

**症状**：终端提示提交成功，但校友邦页面上没看到这一周。

**原因**：通常是页面缓存 / 列表同步延迟；也可能是浏览器里登录的账号和程序使用的账号不一致。

**解决**：
1. 等 1～3 分钟，刷新校友邦页面或小程序列表。
2. 用菜单 `5` 从系统回读归档，看这一篇是否已经在系统里。
3. 确认程序显示的「登录身份」和你要提交的账号是同一个人。
4. **不要立刻反复提交**。长时间确实没有，再检查网络或向老师确认，必要时提 Issue。

### 13. 双击 EXE 没反应 / 被杀毒软件拦截

**症状**：双击 `校友邦周志助手.exe` 后没有任何窗口出现；或刚打开就被 Windows Defender、360、火绒等提示「已阻止」「发现威胁」。

**原因**：
- 单文件 EXE 首次启动要先自解压，**通常 5～10 秒**（杀毒软件扫描时可能更久），不是卡死；
- 单文件版会把自身解压到一个临时目录（约 138MB）。**从 v1.0.0 起，解压目标改为 `%LOCALAPPDATA%\XybJournal`，不再使用系统 `%TEMP%`**，所以火绒/360 那类「拦截程序往临时目录释放文件」的规则一般不再触发；
  - 如果你用的是**更早下载的旧 exe**，它解压到系统 `%TEMP%`，容易被火绒/360 静默拦截，表现就是「点『仍要运行』后没有任何窗口」——**请重新下载最新 exe**；
  - 若新版仍被拦，用下面第 4 条兼容启动器或第 5 条文件夹版；
- 也可能被安全软件误报。用 PyInstaller 打包的单文件 EXE 被误报是非常常见的情况，**不代表程序有病毒**：本项目源码完全公开，可以自己下载源码、用 `build_exe.py` 重新打包验证；
- 少数情况是把 exe 放到了 `C:\Program Files` 等没有写权限的目录，程序启动后保存不了配置而退出。

**解决**：
1. **先等**：双击后等 30～60 秒，不要连续双击。可以打开任务管理器看有没有「校友邦周志助手」进程在运行。
2. **解除锁定**：右键 exe → **属性** → 常规页最下方若出现「**解除锁定 / Unblock**」勾选框，勾上 → 确定；这样就不再弹 SmartScreen。（也可以在 PowerShell 里执行 `Unblock-File -LiteralPath "exe的完整路径"`。）
3. **把文件夹加入安全软件信任区（最彻底）**：
   - **火绒**：打开火绒 → 右上角「**≡**」→「**信任区**」→「添加目录」，选中 exe 所在文件夹；也可以先看火绒主界面「**日志**」，能看到被拦截的记录，右键选择允许；
   - **360 / 电脑管家 / Defender**：拦截弹窗里选「**允许运行 / 保留文件 / 添加信任**」，或到设置里添加信任目录（Defender 路径：Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加文件夹）。
4. **改用兼容启动器（最省事，专治"点了没反应"）**：把仓库里的 `启动-兼容模式.bat` 和 `校友邦周志助手.exe` 放在**同一个文件夹**，双击 `启动-兼容模式.bat` 启动。
   它的作用是把临时目录从系统 `%TEMP%` 改到 exe 旁边的 `_tmp\`，绕开安全软件对系统临时目录的拦截（主程序的任意参数都会原样传递）。
5. **改用文件夹版**：文件夹版**不需要把自身解压到临时目录**，启动只要约 0.3 秒，触发杀软的几率低很多。
   - 下载：Releases 页的 `校友邦周志助手-文件夹版-v1.0.0.zip`；或自己打包：`python build_exe.py --onedir`；
   - 解压后双击里面的 `校友邦周志助手.exe` 即可，数据同样存在该文件夹里。
   - 注意：如果安全软件连程序运行都拦，仍需配合第 3 条的信任区设置。
6. **核对文件 / 换位置**：从本仓库 Releases 页重新下载最新版本，下载后大小约 55MB；把整个文件夹移到 `D:\周志助手\` 这类可写目录再试。可以用 <https://www.virustotal.com/> 看多引擎结果，但这类单文件 EXE 常有个别引擎误报，不能只看检测数量下结论。
7. **仍不行**：改用上面的**源码版**（需要 Python，见「快速开始 → 方式二」），或**先跑一次环境自检**（见 FAQ 第 16 条），再到仓库提 Issue 并附上自检输出和报错文字（记得打码个人信息和 Key）。

> 不确定时**不要**把 exe 转发给别人运行，也不要在网上随便下载来源不明的同名文件。

### 14. 换电脑后登录态和归档还在吗？

**症状**：准备换电脑或重装系统，担心历史周志归档丢失、又要重新扫码。

**原因**：EXE 版是便携版，数据都在 **exe 同目录**：`config.json`（配置和 Key）、`chrome-profile\`（登录态）、`周志记录\`（归档）、`qr.png` 等；源码版则在仓库根目录和 `xyb\` 下。

**解决**：
1. **把整个文件夹一起拷走**：EXE 版 = exe 所在的整个文件夹；源码版 = 整个仓库文件夹（含 `chrome-profile\`、`周志记录\`、`xyb\config.json`）。
2. 新电脑上放到可写目录，双击 exe（源码版双击 `start.bat`）即可：配置、登录态和归档都会保留，通常不用重新扫码。
3. 只拷 exe **不会**带走数据，到新电脑上会回到「首次使用」状态，需要重新填 Key、扫码。
4. 拷贝前先退出程序，避免 `chrome-profile\` 里的文件正被占用；用 U 盘或移动硬盘拷贝即可。
5. 登录态本身会过期，换机器后如果提示要登录，用菜单 `1` 重新扫码。

### 15. 我的信息会被发到哪里？

**症状**：担心周志内容、实习信息、API Key 被上传到不明服务器。

**原因**：本工具需要调用 AI 服务商生成正文，需要访问校友邦读写周志，因此会产生两次外部通信。

**解决 / 说明**：

- **AI 生成时**：程序会把实习单位、岗位、周次、学校要求的字数 / 标题格式，以及你在菜单 `2`
  里填的「本周真实素材」，发送给你配置的 AI 服务商（默认是 DeepSeek），用于生成正文。
  这些内容会按该服务商的隐私政策处理。
- **校友邦操作**：读取实习信息和提交周志，都在你本机安装的 Chrome 里直接访问校友邦完成。
- **本地保存**：API Key、登录态、本地归档都只存在你的电脑本机（EXE 版在 exe 同目录，源码版在仓库目录），不会上传。
- 本项目没有开发者服务器，不会收集、上传你的数据。
- 如果你介意把实习信息发给 AI 服务商，请不要使用本工具，或改用本地模型（见 `docs/AI接口接入.md` 第 5 节）。

### 16. 遇到异常 / 要反馈问题，怎么快速提供信息？

**症状**：程序报错、卡住，或者你想去 GitHub 提 Issue，但不知道要提供哪些信息。

**解决**：先跑一次**环境自检**，它会一次性打印出排错需要的信息：

- **EXE 版**：打开 exe 所在的文件夹，在资源管理器顶部的地址栏输入 `cmd` 后回车，在弹出的窗口里执行：

  ```bat
  "校友邦周志助手.exe" --check
  ```

  约 5 秒会打印：运行方式（EXE 免安装版 / 源码版）、操作系统、程序目录、配置文件路径与是否存在、AI Key 是否配置、模型名、依赖与 Chrome 是否正常、登录状态（已登录会显示姓名和学校；未登录会提示扫码，不会卡住）。
- **源码版**：在仓库根目录打开 PowerShell，执行 `python xyb\cli.py --check`。

只想看版本号：EXE 版执行 `"校友邦周志助手.exe" --version`（源码版执行 `python xyb\cli.py --version`）。

去仓库提 Issue 时，请附上：

1. 自检输出（截图或复制文字）；
2. 完整的报错信息（最后几行）和你的操作步骤；
3. **发之前删掉** API Key、姓名、学号、学校、单位等个人信息，截图里也要打码（自检输出里的姓名、学校同样要打码）。
